# M13 Rising Sun, part 1: plan

Source: `docs/new-design-handoff/HANDOFF.md` (design direction chosen by Pranav, 2026-11-10), its mockups in `docs/new-design-handoff/{screens,png}` and the new requirements FR-DSN-1…9 in `docs/PRD-1.2.md` ("1.3.0 Rising Sun redesign"). M12 stays reserved for the combined coach (PRD-1.2 milestones), so the redesign runs as M13–M16 (D125).

**Rules from the handoff**
- Built on a branch (`m13-rising-sun`), behind the existing UI. The classic Paper & Iron look stays the default and is not removed until Pranav approves the result.
- Mockups are pictures of layout and style. Behaviour comes from the PRD. Every existing feature survives.
- Screens Pranav reviewed: Today, Active workout, Logging, Rest, Progress, Diary, Add food. The others are first drafts: their style is fixed, their layout is a starting point.

**Redesign milestones (handoff §9)**

| Milestone | Scope |
|---|---|
| **M13** (this plan) | Tokens, fonts, sun, glass, buttons, tab bar and the other shared components; Today (S05), Active workout (S06), Logging a set (S07), Rest timer (S25) |
| M14 | Food: Diary (F01), Add food (F02), Portion sheet (F03), Create food (F04) |
| M15 | Echo motion: ripple and celebration (FR-DSN-8) |
| M16 | Everything else, one PRD screen id per change (Progress first, since Pranav reviewed it); then remove the classic look once approved |

**Exit criteria (M13)**
- Settings has a Look switch (Classic / Rising Sun). Classic is the default and renders exactly as before; every existing unit and e2e test still passes untouched.
- In Rising Sun: four themes from tokens (workout or food × light or dark), self-hosted fonts, the sun behind the rebuilt screens, glass cards with an opaque fallback.
- Today, Active workout, Logging and Rest match the mockups in light and dark at 360 and 430 px, with every classic feature still reachable.
- Screens not rebuilt yet stay usable and axe-clean in the new colours and type.
- Typecheck, lint, unit and e2e pass; first-load JS stays under 250 KB; works offline.
