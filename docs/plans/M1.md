# M1 Log a workout: plan

Exit criteria (PRD §12): onboard and log a real workout in under 3 minutes; kill the app mid-session and resume; backup round-trip passes.

## 1. Data
| Task | Files | Req |
|---|---|---|
| Seed script (pinned free-exercise-db snapshot, deterministic rules, report) | scripts/seed.ts, scripts/seed-rules.ts, scripts/vendor/*, src/data/exercises.json, SEED-REPORT.md | FR-LIB-1, FR-LIB-2, FR-GYM-5 (metadata) |
| Seed rule tests (patterns, load types, requires, limitations, renames) | scripts/seed-rules.test.ts | FR-LIB-1 |

## 2. Engines (tests first)
| Engine | Req |
|---|---|
| units.ts: kg⇄lb, display rounding to the unit's increment | FR-SET-2 |
| load.ts: set volume by load type (dumbbell ×2, bodyweight, assisted, bodyweight_plus), effective load | §6.1 |
| e1rm.ts: Epley, reps ≤ 12, effective load | §6.2 |
| prescription.ts: sets / rep range / rest by level, goal modifier, role, nudge (incl. Coach's call text) | FR-GOAL-2, FR-ONB-2 |
| warmup.ts: ramp from intensity.json, first compound per muscle group, min working kg | FR-WRK-7 |
| goalset.ts: goal-set check, bonus reps (D15), unilateral pairs | FR-WRK-8, FR-WRK-14 |
| timer.ts: timestamp-based remaining, ±15 s, skip, done | FR-TMR-1…4 |
| rotation.ts: up-next, advance, skip-to | FR-RTN-4 |
| week.ts: week start, week number, sessions per week | FR-RTN-5, D27 |
| summary.ts: ticket totals (tonnage with bodyweight rules, sets, reps, duration, goal sets, bonus, vs last) | FR-SUM-1 |
| search.ts: normalised prefix + 1-typo fuzzy over names and aliases | FR-LIB-3 |
| split.ts: recommendRule | FR-ONB-4 |
| goal.ts (M1 subset): calibration when no history, otherwise last exposure's load; full rules in M2/M3 | FR-GOAL-4 |

## 3. Illustrations
Port pictos.py → src/illustration (rig, parts, 10 tier-1 exercises, muscle map) with token colours. Test: rendered SVG geometry equals the Python reference (generated by scripts/pictos-ref.py into src/illustration/__ref__/). FR-ILL-1, FR-ILL-3.

## 4. DB repositories
profile, gym, routines/queue, sessions/sets (write-through per set, FR-WRK-13), exercises (catalogue + custom), backup UI.

## 5. Screens
S01, S02 (defaults to full gym; all toggles land in M2), S03, S04 (manual: add, remove, reorder by drag and keyboard, no coverage), S05, S06, S07/S08 (one component), S09 basic, S25 timer, S13 minimal (search + add to session), S14 (units, rest, warm-ups, alert, backup/restore, delete all).

## 6. e2e
#1 onboarding → first set · #2 full session → ticket · #3 offline session · #4 kill/reload mid-session resume · #5 backup export → delete → import. Axe on every new route in both themes.
