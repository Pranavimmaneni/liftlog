- Vite + React 19 + TS strict, ESLint (with a no-hex-colour rule for UI code, and a purity rule for engines) + Prettier, Vitest with coverage gates (70% overall, 90% `src/engine`), Playwright on 4 projects (Pixel 7 / iPhone 14 × Paper / Iron). All CLAUDE.md npm scripts exist.
