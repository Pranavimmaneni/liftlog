## M4 report

**Built**
- **S10 weekly / monthly review (FR-REV-1/2).**
  - Opens on the last completed week. Arrows move between periods, and a Weekly/Monthly toggle switches view.
  - Stats: sessions done against planned, goal sets (counted exactly like the ticket) and new PRs with the best one.
  - **Going well / Needs work.** The §6.7 rules apply in order and the first match wins.
  - **One-tap fixes:**
    - "+ Leg Curl" adds the best in-gym exercise for the weak muscle to the lightest session.
    - "Swap" opens the swap sheet for a stalled or hurting exercise.
    - "Fewer days" handles missed sessions.
  - **"Next week and why"** lists weight changes first, 5 shown, with "Show all". The monthly view adds a per-muscle hard-sets table.
  - Home shows "Week N review is ready" on the first two days of a week (D62).
- **Recomp check (FR-REV-3, §6.8).** Bodyweight and a strength index appear as two single-series sparklines, never a dual axis.
  - Status is "On track" or "Watch", with one line explaining a "Watch", using the rules for each goal.
  - It needs 3 weigh-ins; before that it shows an empty state saying how many more are needed.
- **S11 strength levels (FR-STR-1/2/3).**
  - Benchmark lifts only, with thresholds by sex × age.
  - Five-band bar with a marker, "Next: Intermediate at 117.6 kg · ~5 weeks at this pace", or months, or "Keep logging…".
  - A "Guideline values" chip shows while standards.json `source` is TODO (D23).
  - Groups trained only on machines get a card saying which lift unlocks them (FR-STR-2).
  - It ends with "General guidelines, not medical advice".
- **S19 body stats.** Sex, birth year and bodyweight. Every field is optional and explained. It opens first from S11 only when nothing is known, and "Skip" means "prefer not to say", so it isn't asked again (D64).
- **S12 progress hub (FR-PRO-1).**
  - **Lifts:** exercise picker, estimated 1-rep max chart by week with a table view, a "This week" card linking to the review, a Strength card linking to S11, and the PR list.
  - **Body:** recomp card, weigh-ins chart and list with delete, and a link to body stats.
  - **History:** session list linking to S18.
- **S18 session detail.** The ticket numbers plus every set. Tap a set to edit or delete it (the same sheet as the logger). "Delete session" asks for confirmation and rebuilds PRs.
- **Every chart has a table view**, and the recomp sparklines have text labels. The chart's "Show as table" toggle no longer floats; that had broken layouts.

**Also fixed / improved:**
- S19 could overwrite a quick first tap with the saved values. It now renders once the saved values have loaded.
- The review builds its per-session numbers from the log in memory: one query per table instead of several per session.
- Demo fixture: one transaction per session, plus `?weeks=N`.
- Line endings: 3 files had CRLF from scripts. `.gitattributes` now forces LF.
