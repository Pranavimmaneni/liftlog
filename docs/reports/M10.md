## M10 report: food data and engines

Built:
- **Food library (FR-FOOD-1, FR-FOOD-6, FR-FOOD-7, NFR-LIC-2):** `npm run seed:foods` builds 23,365 foods from pinned USDA sources (public domain): 5,354 generic foods (FNDDS), 147 Indian dishes (calculated from standard recipes), and 17,864 branded foods from 16 brand groups (Walmart, Target, Kroger, Whole Foods, Sam's Club, Costco, Trader Joe's, Indian grocery brands and others). The size is 1.04 MB compressed. `FOOD-SEED-REPORT.md` lists all filters, caps and dropped rows.
- **Schema version 2 (NFR-REL-6, FR-SHR-2):** new tables for the library, your own foods and recipes, the diary, saved meals and fasts, and optional profile fields (height, activity, diet phase). The change only adds data. Tests prove that a version 1 database and a version 1 backup upgrade with every training row unchanged. Backups now include the food tables, but not the library.
- **Repositories (FR-DIARY-1..3, FR-FOOD-2/4/5, FR-FAST-1, NFR-OFF-3):** log, edit, delete and copy diary entries (each entry keeps a copy of the nutrients); saved meals; quick add; own foods and recipes; barcode lookup (14 digits); fasts; library import one time per version in the background.
- **Engines (FR-TGT-1..6, FR-FOOD-3, FR-COACH-1..3, FR-NUT-1/2, FR-FAST-1, FR-GAME-1, NFR-PERF-5):** energy (Mifflin-St Jeor), macros, micros (US intake values), adaptive expenditure, food search (less than 150 ms over 30,000 foods in the test), the link to LiftLog data (usual training time, volume, strength), day and period reviews, combined coach rules with fixes, fasting maths, food quests, XP and streak. For the mockup's sample person, the result is 2,950 kcal, 140 g protein, 440 g carbs and 70 g fat, the same as F05.
- **`/dev/food`:** library status, import, timed search, and the sample targets.

Deviations:
- The library is 1.04 MB compressed, not about 2 MB. USDA has few Costco (132) and Aldi (3) products (D112).
- Indian dishes are calculated from recipes, because IFCT 2017 has no open licence (D111).
- The paneer ingredient uses whole-milk mozzarella, because the USDA "Cheese, paneer" row has implausible carbs (D110).
- The background import does not run under test automation; e2e imports through `/dev/food` (D101).
- Food quest XP values are in `xp.json` under `food`. Adding them to the shared level is M12 (D108).

Decisions logged: 14 (D100–D113; D89–D99 are reserved for M8). Important: D100 (library in IndexedDB, not in the precache) and D104 (usual training time from history, because LiftLog has no planned times).

Tests: 418 unit tests pass (343 before M10). Coverage: `src/engine` 99.3%, overall 85.3%. 14 seed tests in `scripts/foods`. E2E: 144/144 pass on Pixel 7 and iPhone 14, Paper and Iron (Chromium imports the whole library and searches offline; WebKit imports the Indian chunk, D113). First-load JS: 164.2 KB (budget 250 KB). Precache: 2.66 MB (budget 5 MB); the food files are not in it.

Deployed: not deployed. M10 has no Food screens yet, so the work stays on branch `m10-food-data` until M11 (plan). Before the first deploy with schema version 2, make a backup.

Phone checks for Pranav: see `docs/reports/PHONE-CHECKS.md` § M10 (they need a preview deploy of this branch).

Known issues:
- Branded foods have few micronutrients (labels give vitamin D for about 6,900 and B12 for about 900 products). Reviews treat missing values as unknown, not zero.
- Indian dish values are estimates of typical home recipes.
- Under heavy CPU load, the S17 screen test once exceeded its 8 s wait. It passes alone and in the full run.
- Playwright's WebKit on Windows writes IndexedDB slowly, so the full-library import on an iPhone is measured only by the phone check (D113).
- The M8 session still runs on its own branch; its work is not in this branch.
