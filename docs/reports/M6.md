## M6 report

**Built**
- **Capacitor 8 Android app** (`app.liftlog`, D73). `npm run build:native` makes the APK's web bundle (relative paths, hash routing, no service worker), so it works offline from the first launch. `npm run cap:sync` copies it into `android/`.
- **Native platform adapter** (`src/platform/native.ts`). Feature code still only talks to `src/platform`, and plugins load lazily, so the web bundle never downloads them.
  - Keep-screen-on for the whole session (FR-PLT-2).
  - A **local notification when rest ends with the phone locked** (FR-PLT-4). It asks for permission once, uses one fixed id, and is cancelled when rest is skipped or the next set is logged.
  - Haptics on logging a set and at rest end (FR-PLT-3).
  - Backups and ticket images go through the Android share sheet, via a cache file. With no share target, a copy is saved to Documents (FR-PLT-6).
  - Status bar colour and icon style follow Paper and Iron (FR-PLT-9).
  - Durable storage (FR-PLT-7).
  - The camera works for QR scanning through the WebView, using Chrome's native BarcodeDetector (FR-PLT-5).
- **Android manifest:** camera, notifications, exact alarms (D75), vibrate and wake-lock permissions.
- **Icons and splash (D76):** LL monogram launcher icons, Paper and Iron splash screens (Iron in night mode), and a white vector notification icon. 74 generated resources.
- **CI:** `.github/workflows/android-apk.yml`, copied from `ci/android-apk.yml`.
  - Builds a **debug APK** on demand. It also smoke-tests the native bundle and fixes the `gradlew` executable bit.
  - Builds a **signed release APK** when the keystore secrets are set: `build.gradle` reads them from the environment.
- **Version 1.0.0** (package.json, versionName) and **`docs/RELEASE.md`**: bumping versions, web deploys, the debug APK, creating a keystore and signing a release, moving data between web and APK.

**Deviations:** the APK wasn't built on this PC because there is no JDK or Android SDK (D74). It is built by the GitHub workflow. Here, the native web bundle passes a Playwright smoke test (onboarding → log a set with hash routing, no service worker), and the adapter has unit tests against mocked Capacitor plugins.
