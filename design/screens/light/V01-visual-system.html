Illustration rules
  1. Side view, figure faces right. Thick round-capped strokes, detached head (1972 Munich pictogram style).
  2. Faint ghost figure = start position. Solid figure = finish position. Red dotted arrow = the path of the weight.
  3. Near arm gets a background-coloured outline so it reads over the torso.
  4. Equipment in warm grey (both themes), drawn from simple parts: pads, frame, pulley, weight stack with a red pin.
  5. Muscle map: front and back. Red = main muscle, brass = helpers. Reused for every exercise.
  6. Every pose is data (joint angles), so the app can animate start → finish and add exercises without an artist.
